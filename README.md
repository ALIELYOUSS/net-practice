# NetPractice

A networking training project designed to help students understand TCP/IP addressing and network configuration through interactive exercises.

---

## Description

**NetPractice** is a 42 school project focused on learning and practicing network configuration concepts. The project provides an interactive web-based training interface where users must configure small-scale networks to make them functional.

## Instructions

### Running the Training Interface

1. Install the project package from the intranet project page:
   - Click the `net_practice.1.8.tgz` link on your intranet project page to download it via your browser.
   - After the file is downloaded, extract it locally. Example commands (no download command needed if you used the browser):
   ```bash
   install the net_practice.1.8.tgz
   tar -xzf net_practice.1.8.tgz
   cd net_practice
   ```

2. Open the training interface in your web browser:
   ```bash
   open index.html
   ```
   Or simply double-click on `index.html` to open it in your default browser.

3. Enter your 42 intranet login when prompted and click **"Start!"** to begin training.

4. Navigate through levels 1-10, configuring each network diagram correctly.

### Submission Requirements

**Important:** For project submission, you must place **10 exported configuration files** (one per level) at the root of your Git repository:
